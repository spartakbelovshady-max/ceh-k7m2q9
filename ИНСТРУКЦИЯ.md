# ЦЕХ — публикация и установка

Версия приложения 11, кэш ceh-v12. Код доступа: **5050**

---

## ЧТО ЗАЛИВАТЬ — 6 ФАЙЛОВ

| Файл | Зачем нужен | Можно ли переименовать |
|---|---|---|
| `index.html` | Само приложение | НЕТ |
| `sw.js` | Работа без интернета | НЕТ |
| `manifest.json` | Кнопка «Установить» | НЕТ |
| `robots.txt` | Скрыть от поисковиков | НЕТ |
| `icon-192.png` | Иконка на рабочем столе | НЕТ |
| `icon-512.png` | Иконка крупная | НЕТ |
| `icon-maskable.png` | Иконка для Android | НЕТ |

Итого семь файлов. Имена строго такие — иначе установка и офлайн не заработают.

---

## ШАГ 1. СКАЧАТЬ ФАЙЛЫ

1. Нажмите на каждый файл в чате → «Скачать».
2. Откройте «Проводник» → папка **Downloads**.
3. Проверьте имена. Если браузер дописал `(1)` — переименуйте: долгое нажатие на файл → «Переименовать».

---

## ШАГ 2. АККАУНТ НА GITHUB

1. Откройте **github.com** в Chrome.
2. Кнопка **Sign up**.
3. Введите почту → **Continue**.
4. Придумайте пароль → **Continue**.
5. Придумайте имя пользователя латиницей, например `ceh-saransk`.
   **Это имя войдёт в адрес приложения**, выбирайте то, что не жалко показать.
6. На вопрос про рассылку введите `n` → **Continue**.
7. Решите картинку-головоломку.
8. На почту придёт код из 8 цифр — введите его.
9. На вопросы «сколько человек в команде» и т.п. можно нажать **Skip**.

---

## ШАГ 3. СОЗДАТЬ РЕПОЗИТОРИЙ

1. Справа сверху значок **+** → **New repository**.
2. **Repository name**: придумайте с добавкой случайных букв и цифр.
   Хорошо: `ceh-k7m2q9`  ·  Плохо: `ceh`
   Так ссылку не подберут перебором.
3. **Description** оставьте пустым.
4. Обязательно **Public**. На бесплатном тарифе публикация работает только так.
   Это значит, что виден исходный код, но не значит, что сайт попадёт в поиск — за это отвечает robots.txt.
5. Галочку «Add a README file» НЕ ставьте.
6. Кнопка **Create repository**.

---

## ШАГ 4. ЗАГРУЗИТЬ ФАЙЛЫ

1. На открывшейся странице найдите ссылку **uploading an existing file**.
   Если её нет: **Add file** → **Upload files**.
2. **Choose your files** → откроется файловый менеджер.
3. Зайдите в **Downloads**, выделите **все семь файлов сразу**
   (долгое нажатие на первом, потом отметить остальные).
4. Дождитесь загрузки. `index.html` весит 335 КБ — на медленном интернете это займёт минуту.
5. Проверьте: в списке должно быть ровно 7 файлов.
6. Внизу зелёная кнопка **Commit changes**.

---

## ШАГ 5. ВКЛЮЧИТЬ САЙТ

1. Вверху страницы репозитория вкладка **Settings** (шестерёнка).
   На телефоне она может прятаться под значком «···».
2. В левом меню найдите **Pages**.
3. Раздел **Build and deployment**, поле **Source**: выберите **Deploy from a branch**.
4. Ниже **Branch**: выберите **main**, папка **/ (root)**.
5. Кнопка **Save**.
6. Подождите 2 минуты и обновите страницу. Вверху появится:

   `Your site is live at https://ваше-имя.github.io/ceh-k7m2q9/`

**Это и есть ссылка на приложение. Сохраните её.**

Если написано «Your site is being built» — просто подождите ещё минуту.

---

## ШАГ 6. УСТАНОВИТЬ НА ТЕЛЕФОН

1. Откройте ссылку в **Chrome** (не в браузере из мессенджера).
2. Появится чёрный экран — введите **5050** → **Войти**.
3. В шапке появится жёлтая кнопка **Установить**. Нажмите → **Установить**.
   Если кнопки нет: меню **⋮** → **Установить приложение**.
4. Иконка «ЦЕХ» встанет на рабочий стол.
5. **Важно:** один раз при интернете полистайте все вкладки — приложение закэшируется.
   После этого работает в зале без связи.

---

## ШАГ 7. РАЗДАТЬ КОЛЛЕГАМ

1. Отправьте им ссылку и код **5050**.
2. Каждый открывает в Chrome и жмёт «Установить».
3. Чтобы не заполнять аллеи заново: у себя откройте вкладку **Моё** →
   **Скопировать код** → отправьте текст коллеге.
   Он вставляет его в поле «Вставьте сюда код от коллеги» → **Загрузить настройки**.

---

## КАК СМЕНИТЬ КОД ДОСТУПА

1. Репозиторий → файл `index.html` → значок карандаша **✏️**.
2. Меню **⋮** → **Find** → введите `ACCESS_CODE`.
3. Найдите строку `const ACCESS_CODE = "5050";` и замените цифры.
4. **Commit changes**.
5. В файле `sw.js` поднимите версию: `ceh-v12` → `ceh-v13`.

Помните: код виден в исходнике страницы. Он защищает от случайного человека, а не от специалиста.

---

## КАК ОБНОВЛЯТЬ

Когда придёт новая версия:

1. Репозиторий → **Add file** → **Upload files**.
2. Загрузите новые `index.html` и `sw.js` поверх старых.
3. **Commit changes**.
4. Версию кэша в `sw.js` я поднимаю сам — у всех обновится автоматически
   при первом открытии с интернетом.
5. Проверить у себя: вкладка **Моё** → **Проверить обновление**.

Номер версии виден там же и в подвале приложения. Если у коллеги цифра меньше — пусть нажмёт «Проверить обновление» при включённом интернете.

---

## ЕСЛИ ЧТО-ТО НЕ РАБОТАЕТ

**Открывается пустая страница** — прошло меньше двух минут после Save, подождите.

**404 Not Found** — файл называется не `index.html`, либо в Pages выбрана не та ветка.

**Нет кнопки «Установить»** — открыли не в Chrome, либо не хватает `manifest.json` или иконок. Проверьте, что залиты все семь файлов.

**Не работает без интернета** — не залит `sw.js`, либо приложение ни разу не открывали при связи.

**У коллеги старая версия** — вкладка «Моё» → «Проверить обновление» при включённом интернете.
